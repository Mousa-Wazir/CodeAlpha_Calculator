# CodeAlpha_Calculator

**Frontend Development Internship — Task 2: Build a Calculator**

## Features
- **All Arithmetic Operations**: Addition (`+`), Subtraction (`−`), Multiplication (`×`), Division (`÷`), Percentage (`%`), and Sign Toggle (`±`).
- **Real-Time Result Preview**: Shows live calculation previews as you type your expression.
- **Interactive History**: Click any previous calculation in the history panel to reuse its result.
- **Bonus — Full Keyboard Support**: Type numbers (`0-9`), operators (`+`, `-`, `*`, `/`), `Enter` (`=`), `Backspace` (`DEL`), and `Esc` (`AC`).
- **Bonus — Dark & Light Theme**: Switch between dark and light styling modes.

## Project Files
- `index.html` — Calculator structure and layout
- `style.css` — Responsive CSS Grid keypad and dark/light theme variables
- `script.js` — Calculation logic, real-time display, history, and keyboard listeners
